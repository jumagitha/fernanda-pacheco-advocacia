# BlocoContato

Rodapé e seção de contato: logo vertical e dados em lista com rótulos em dourado.

- Forneça: o logo do tema e os dados **confirmados**; enquanto não confirmados, mantenha os marcadores `[… a confirmar]` com a classe `fp-pendente`.
- Nunca publique telefone, e-mail ou endereço de exemplo; nunca anuncie "24h".
- A inscrição na OAB aparece sempre no formato "OAB/UF número".
