# Localidades

Etiquetas com as regiões atendidas, para SEO local honesto e para o rodapé.

- Forneça: `<ul class="fp-locais">` com um `<li class="fp-local">` por cidade, no formato "Cidade — UF".
- Use apenas as regiões confirmadas; não sugira endereço físico enquanto ele não estiver contratado.
- Sempre acompanhe a frase "Atendimento remoto e presencial mediante agendamento."
