# CardAtuacao

Grade de frentes de atuação separadas por linhas finas, cada uma com número editorial dourado, título, uma frase e link.

- Forneça: `<div class="fp-atuacoes">` com até três `<article class="fp-atuacao">`; para mais itens, use LinhaServico.
- O número (`numero`, cor `detalhe`) substitui ícones; mantenha a ordem 01, 02, 03.
- Frase de uma linha e meia no máximo, sem promessa de resultado.
- No celular, os cards empilham com linha entre eles.
