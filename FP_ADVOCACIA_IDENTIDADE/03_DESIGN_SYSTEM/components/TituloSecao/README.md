# TituloSecao

Abertura padrão de qualquer seção: sobretítulo em maiúsculas com filete dourado, título editorial e uma ou duas frases de apoio.

- Forneça: `<div class="fp-titulo-secao">` com `<p class="fp-sobretitulo">`, `<h2 class="fp-h2">` e `<p class="fp-corpo">`.
- Sobretítulo de duas a três palavras (área ou tema); título com no máximo 8 palavras, terminando em ponto quando for afirmação.
- Use `fp-h1` em página interna e `fp-display` só no hero.
- O filete após o sobretítulo é automático; não acrescente outro detalhe dourado no mesmo bloco.
