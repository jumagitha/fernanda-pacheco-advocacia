# Site de Advocacia

Projeto do site profissional de advocacia.

Objetivo inicial:
- apresentar atuação jurídica com foco claro;
- evitar aparência de escritório generalista;
- priorizar conteúdo útil e linguagem acessível;
- trabalhar presença digital e páginas por área de atuação.

Áreas inicialmente consideradas:
- Direito Criminal, com destaque para audiência de custódia e ANPP;
- Direito das Pessoas Autistas;
- Direito de Família.

Região de atuação pretendida:
- Entorno do DF/GO, com foco especial em Novo Gama, Cidade Ocidental, Céu Azul e Luziânia;
- Brasília/DF como atuação complementar.
